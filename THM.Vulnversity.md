# TryHackMe: Vulnversity

**Сложность:** Easy  
**Ключевые уязвимости:** Обход загрузки файлов (.phtml), PrivEsc через SUID (systemctl).

## Разведка
1. Сканируем цель через `nmap -sS -sV -Pn -O`. Открыты порты: 21, 22, 139, 445, 3128, 3333. На порту 3333 работает HTTP.
2. `gobuster dir -u http://IP:3333 ...`: находим директорию `internal` с формой загрузки. Потенциальная точка входа.

## Эксплуатация
1. Запускаем слушатель: `nc -lvnp 4444`.
2. Пытаемся загрузить `.php` шелл — не проходит (базовая защита).
3. Меняем расширение на `.phtml` — файл загружается.
4. Брутфорсим директории внутри `internal`, находим папку `uploads`.
5. Переходим по URL к нашему файлу, получаем reverse shell от `www-data`.
6. Забираем флаг в `/home/bill/user.txt`.

## Повышение привилегий (PrivEsc)
1. Стабилизируем шелл через pty: `python3 -c 'import pty; pty.spawn("/bin/bash")'`.
2. Ищем SUID: `find / -perm -4000 -type f 2>/dev/null`.
3. Находим `systemctl`. Идем на GTFOBins, берем пейлоад для создания кастомной службы.
4. Служба копирует bash в `/tmp` с SUID и запускает его.
5. Получаем рут, читаем `/root/root.txt`.
